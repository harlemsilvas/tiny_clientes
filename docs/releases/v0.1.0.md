# Release v0.1.0

Primeira entrega funcional do projeto `Tiny Clientes`.

## Destaques

- importacao de base CSV de clientes;
- persistencia local em `SQLite`;
- opcao de uso com `PostgreSQL`;
- interface web para consulta e manutencao de cadastros;
- CRUD basico de clientes;
- documentacao inicial para execucao local.

## Fluxo recomendado de validacao

```bash
./run.sh
```

Depois abrir:

```text
http://127.0.0.1:5000
```

## Escopo desta versao

- uso local no WSL ou Linux;
- foco em base unica de clientes;
- interface administrativa simples e direta.

## Proximos passos sugeridos

- exportacao de resultados filtrados;
- mascaras e validacoes de campos;
- separacao real de abas de endereco e cobranca;
- captura de screenshots reais da aplicacao em execucao.
